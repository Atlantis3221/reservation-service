# Монетизация и пивот: рабочие гипотезы

Документ фиксирует стратегические идеи по монетизации Slotik в связке с возможным пивотом из ниши «бани/глемпинги». Не план, а каталог гипотез для проверки.

## Контекст пивота

### Почему текущая ниша (бани/глемпинги) структурно слабая

- **Маленький TAM**: ~5–8K коммерческих бань-на-дровах + ~1.5K глемпингов в РФ. Потолок при 100% охвате × 300₽ ≈ 4M₽/мес — нерабочая SaaS-экономика.
- **Тетрадка реально решает задачу** для владельца с 1–5 объектами. 300₽/мес = «ещё одно лишнее списание».
- **Сезонность** (глемпинги) + **возраст ICP 40–55** → низкое цифровое проникновение и плохой retention.
- **Нет точки агрегации**. Авито/2GIS обходить вручную, не масштабируется. Контекст по «онлайн запись баня» — единицы запросов в день.
- **Защищаемость = 0**. Altegio/YClients добавят шаблон «баня» за месяц, если ниша оживёт.
- **Сигналы из go-to-market**: 50 сообщений → 3 подключения, и подключения бесплатные. Классический паттерн dead niche.

### Что у Slotik по факту есть

Не «софт для бань», а горизонтальный slot-engine с уникальной фишкой: **управление расписанием через мессенджер (TG/VK) + LLM-парсер команд**, а не через тяжёлую CRM. ~10K строк TS, 30 готовых фич, мультитенант, заявки, тарифы, мониторинг, демо.

### Опции пивота (в порядке реализма)

**Опция Б — расширение ICP до «арендуемых пространств по слотам»** (приоритет №1)
- Корты (теннис/падел), escape rooms, бильярдные, караоке, прокат SUP/велов, тиры, борцовские маты
- TAM в 5–10× больше, чем баня, круглогодичный спрос
- Это не пивот, а расширение: те же скрипты go-to-market, замена «баня» → «корт/квест/прокат» в 2GIS
- DIKIDI/YClients там слабо представлены

**Опция А — самозанятые мастера beauty/wellness** (приоритет №2, только при определённых условиях)
- ~500K самозанятых в beauty в РФ, живут в мессенджерах
- Прямой конкурент — **DIKIDI**, не YClients
- DIKIDI moat = бесплатный навсегда для одиночки + маркетплейс с трафиком клиентов
- Slotik wedge = TG/VK-чат вместо приложения, современный UX, быстрый онбординг (3 мин vs 30–60 мин у DIKIDI)
- **Условие входа**: обязательно free tier и канал через TG-сообщества проф-мастеров (не массмаркет, не Reels — там DIKIDI доминирует)
- Позиционирование: «инструмент для тех, у кого уже есть клиенты», не «приложение для поиска мастеров»

**Опция В — психологи/онлайн-консультанты** (отложить)
- Высокая платёжеспособность (1500–3000₽), но нужны видеосозвон + оплата + согласия + регуляторика. Большой объём доработок, не первый шаг.

### Антипаттерны

- Сидеть в бане ещё 6 месяцев в надежде на платящих
- Делать клон YClients (ЗП мастеров, склад, касса) — проигранная война
- Конкурировать с DIKIDI ценой подписки — у них 0₽, не выиграть
- Запускать платную рекламу до валидации платящих пользователей

## Монетизация при free-tier для одиночки

Free-tier — это **канал привлечения, а не источник денег**. Деньги берутся либо транзакционно, либо с тех, кто перерос «одиночку».

### 1. Комиссия с предоплат — главный источник (transactional)

Самая мощная модель для horizontal booking. Так зарабатывают Calendly, Cal.com, SquareSpace Scheduling.

- Интеграция с ЮKassa/Tinkoff Pay, мастер берёт предоплату 30–50% за услугу
- Комиссия Slotik 1.5–2% поверх эквайринга (или фикс 10–15₽ за транзакцию)
- Мастеру выгодно: предоплата снижает no-show на 60–80%
- Расчёт: 100 записей × 2000₽ × 30% × 1.5% ≈ **900₽/мес с одного активного мастера** (× 3 от подписки)

Главный KPI становится **% мастеров с подключённой предоплатой** и **GMV через платформу**, а не «конверсия в подписку».

DIKIDI это плохо закрывает — у них предоплаты есть, но через маркетплейс (клиент платит DIKIDI, а не салону), UX тяжёлый. Здесь реальный шанс обыграть.

### 2. Freemium upsell по фичам (когда бизнес растёт)

| Триггер | Цена/мес |
|---|---|
| 2-й мастер / помощник | 400₽ |
| 2-й объект (бани/корты/кабинеты) | 300₽ |
| Свой домен (mybusiness.ru) | 200₽ |
| Снятие вотермарки «Powered by Slotik» | 150₽ |
| >100 бронирований/мес | 300₽ |
| Заявки + ручное подтверждение | 200₽ |
| Экспорт CSV / API | 300₽ |

Логика: одиночка с 30 записями платит 0₽ и приводит сарафан. Активный — естественно перерастает в платный.

### 3. Связь и уведомления с наценкой (sticky)

- **SMS**: закуп ~2.5₽, продажа ~4₽ = 60% маржа. Активный мастер: 200 SMS × 1.5₽ = 300₽/мес
- **WhatsApp Business API**: ~7–12₽/сообщение, наценка 30–50%
- **Робозвонок-напоминание**: ~6₽/звонок, наценка 100%

Клиенты привыкают и не отключают.

### 4. Партнёрские/реферальные деньги

- **Тинькофф/Сбербизнес/Точка**: 500–3000₽ за подключённого ИП/самозанятого. У Slotik 100% попадание в ICP — мастера регистрируют ИП/самозанятость
- **ЮKassa/CloudPayments**: реф-бонус за мерчантов + revenue-share с оборота (0.05–0.1%)
- **2GIS Pro / Авито Pro**: cross-sell партнёрки
- **Страхование ответственности мастера**: узкий, но платёжеспособный канал

### 5. Мост к B2B-тарифу (когда мастер вырос в салон)

Естественный апсейл 800–2500₽/мес, когда:
- 3+ мастера
- Появился администратор
- Нужна аналитика ЗП

«Slotik Pro для салона» — отдельный продукт без free.

### Чего не делать

- **Не продавать данные** мастеров рекламодателям — убьёт доверие
- **Не делать freemium с лимитом 5 записей** — раздражает, выглядит дёшево, лиды уйдут к DIKIDI
- **Не монетизировать LLM-чат** через лимиты — это главная фишка, отрезать её = убить продукт

## Реалистичная цель на 12 месяцев

При 2000 free-мастеров + 200 платных + 30% подключают предоплаты:

| Источник | MRR |
|---|---|
| Платные подписки (200 × 400₽) | 80K₽ |
| Комиссия с предоплат (600 × 500₽) | 300K₽ |
| SMS markup (300 active × 200₽) | 60K₽ |
| Партнёрские (ИП через мастеров) | 30K₽ |
| **Итого** | **~470K₽/мес** |

Transactional + freemium-upsell ≈ 80% выручки, подписка одиночек ≈ 0₽ — и это правильно.
